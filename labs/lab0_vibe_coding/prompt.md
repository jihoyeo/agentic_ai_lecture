AI 코딩 에이전트한테 넘겨줄 상세 빌드 스펙 문서를 마크다운으로 작성해줘. 미리 만들어둔 코드는 없고 바이브코딩으로 처음부터 만들 수 있게 아키텍처, 데이터 구조, AI 도구 세팅, 단계별 빌드 과정을 아주 구체적으로 명세해줘.

1. 개요 및 화면 구성

* 수도권 통근 흐름을 보여주는 지도와 데이터 질문에 답하는 AI 채팅 에이전트가 있는 단일 페이지 웹 앱.
* 화면 왼쪽 65%는 지도, 오른쪽 35%는 채팅창으로 구성하고 스크롤 없는 데스크톱 뷰로 만들어줘.

2. 데이터 및 지도 시각화
* 데이터: 
    - cities.json(도시 id, 이름, 위경도)
    - flows.json(출발지, 도착지, 통근량)
* 스택: React, Vite, deck.gl, VWorld 베이스맵 사용.
* 시각화: 도시는 점(총 통근량에 비례해 크기 설정), 통근 흐름은 곡선(통근량에 비례해 굵기 설정)으로 그려줘.

3. AI 채팅 에이전트 (핵심)

* 모델: Gemini 2.5 Flash API 사용.
* AI Agent의 기능 정의
    1. 도시 찾기 (도시 이름 입력하면 해당 도시 정보 출력)
    2. 두 도시 간 단방향 통근량 출력
    3. 두 도시 간 왕복 통근량
    4. 특정 도시의 총 유입/유출량
    5. 통근량 상위 N개 구간
* 동작 방식: LLM이 필요에 따라 도구를 여러 번 호출하는 멀티스텝 에이전트 루프 구조
